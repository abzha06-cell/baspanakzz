# Алматыдан үй іздеу көмекшісі

Бастапқы жарнам немесе бюджет бойынша ипотеканы есептейді, ал Google Gemini (Google Search арқылы) Алматыдағы сай пәтерлерді табады.

- `index.html` – сайттың беті және ипотека калькуляторы
- `api/search.js` – Gemini API-ге сұрау жіберетін серверлік функция
- `vercel.json` – функцияға 60 секундқа дейін жұмыс істеуге рұқсат

Vercel-де Environment Variables бөліміне `GEMINI_API_KEY` қосу керек.
